# MonoForge Project Specification & Vision

## 1. Executive Summary
**MonoForge** is an open-source Developer Identity & Creative Visualization Platform. It transforms real software engineering telemetry (GitHub contributions, repository velocity, polyglot distribution, coding rhythms) into high-impact visual experiences, interactive 60fps web portfolios, and GitHub Camo-safe profile READMEs.

## 2. Product Identity
- **Name**: MonoForge (formerly ReadmeForge)
- **Web Studio**: [https://monoforge-studio.vercel.app](https://monoforge-studio.vercel.app)
- **Repository**: [https://github.com/yuvraj-thakur-exe/MONOFORGE](https://github.com/yuvraj-thakur-exe/MONOFORGE)
- **Primary Persona**: Senior Open-Source Maintainers, Full-Stack Architects, Technical Writers, DevRel Engineers, and Student Builders.

## 3. Core Pillars
1. **Developer Identity Revolution**: One single source of live GitHub data powers 9 signature visual architectures (Commit City, River, Year Clock, Pulse, Terminal, Snake, Galaxy, DNA, Constellation).
2. **Dual-Mode Output Pipeline**:
   - *Interactive Portfolio Mode*: HTML5 Canvas with 60fps physics, mouse hover inspection, speed multiplier, and replay controls.
   - *GitHub README Mode*: Camo-safe vector SVG with embedded `@keyframes`, zero `<script>`, zero `<foreignObject>`, and automated dark/light mode switching.
3. **Comprehensive Studio Suite**:
   - 200+ production-ready presets across 12 disciplines.
   - Live multi-device viewport switcher (Desktop 100%, Tablet 768px, Mobile 375px).
   - Realistic GitHub Profile Simulation tab with repository pinned cards and user sidebar.
   - Side-by-side Template Comparison Matrix.
   - README Doctor diagnostic health engine (0-100 score with 1-click auto-fixes).
