## Issue Categories & Templates

### 1. Bug Reports
If you encounter a Camo rendering failure, markdown parsing discrepancy, or UI issue:
- Include the browser version, OS, and Node version.
- Include the profile configuration JSON or raw Markdown input.
- Check browser console and network tab for any failed SVG or API responses.

### 2. Feature & Module Requests
When proposing new developer telemetry engines, visual archetypes, or animation presets:
- Describe the developer persona or use case.
- Provide mockup SVGs or visual references where applicable.
- Confirm that the proposed feature adheres to GitHub Camo rules (0 `<script>`, 0 `<foreignObject>`).

### 3. Community Asset Submissions
To propose assets for inclusion in the Community Asset Marketplace:
- Reference the metadata schema in `docs/COMMUNITY_ASSETS.md`.
- Ensure permissive licensing (MIT, Apache-2.0, or CC-BY-4.0).
