# MonoForge AI Prompt Library & Slash Commands

This document centralizes all canonical prompts, slash commands, and role specifications for MonoForge.

## 1. AI Slash Command Reference

| Command | Pipeline & Function | Example Prompt |
|---|---|---|
| `/create` | Generate an end-to-end profile README from scratch | `/create Senior Distributed Systems Architect with 3D Commit City` |
| `/visual` | Inject one of 9 signature visual architectures | `/visual Commit River with ocean cyan theme` |
| `/animate` | Generate GPU-accelerated 60fps SVG animation | `/animate Contribution Snake moving across 52-week calendar` |
| `/chart` | Generate data-driven telemetry charts | `/chart Polyglot languages donut with TokyoNight theme` |
| `/diagram` | Author GitHub-native Mermaid technical diagrams | `/diagram Flowchart showing edge mesh architecture` |
| `/banner` | Generate dynamic hero banners | `/banner Neon outrun cyber grid with typewriter typography` |
| `/component` | Author a new reusable profile module | `/component Spotify now-playing cassette player widget` |
| `/import` | Parse and reconstruct existing Markdown into visual blocks | `/import https://github.com/octocat/octocat` |
| `/redesign` | Morph existing README into a new visual style | `/redesign Switch from Minimalist to Cyberpunk Neon` |
| `/optimize` | Improve markdown readability, contrast, and structure | `/optimize Audit section hierarchy and balance badge alignments` |
| `/doctor` | Run automated README Doctor audit | `/doctor Scan markdown for broken URLs, missing alt text, and Camo errors` |
| `/export` | Output final deployment bundle | `/export Download README.md and copy Camo SVG links` |

## 2. Master System Prompt for README Creator Agent
```markdown
Act as a Principal Software Architect, Graphics Engineer, and Senior Open-Source Maintainer.
Your mission is to transform a developer's real software engineering data into an exceptional GitHub Profile README and interactive portfolio.
Guidelines:
1. Always utilize real GitHub contributor data or verified project repositories. Never fabricate metrics.
2. Adhere strictly to GitHub Camo proxy rules (zero <script>, zero <foreignObject>, pure CSS animations).
3. Ensure high-contrast visual accessibility and responsive presentation.
4. Support both Interactive Portfolio Canvas mode and GitHub README SVG mode.
```
