# MonoForge Visual Asset Builder (`visual-asset-builder`)

The **Visual Asset Builder** powers the graphics, vector motion, and Canvas rendering pipeline of MonoForge 3.0.

## Supported Renderers

1. **Interactive Portfolio Canvas Mode**:
   - High-density 60fps HTML5 Canvas with device pixel ratio scaling (`dpr <= 2`).
   - Battery-friendly visibility awareness (`document.visibilityState`).
   - Real-time mouse hover inspection, zoom, and speed multiplier controls.

2. **GitHub README Mode (Camo-Safe SVG)**:
   - Standalone valid XML vector SVG.
   - Zero `<script>` and zero `<foreignObject>`.
   - Embedded `@keyframes` animations utilizing GPU-friendly `transform` and `opacity`.
   - Native dark/light mode switching.

3. **Technical Diagrams (Mermaid)**:
   - Flowcharts, sequence diagrams, architecture blueprints, release timelines.
   - Rendered natively in GitHub Markdown without external dependencies.

4. **Telemetry & Badges (Shields & Simple Icons)**:
   - Technology badge grids formatted with `for-the-badge` or `flat-square`.
   - Standardized colors aligned with Simple Icons brand specifications.
