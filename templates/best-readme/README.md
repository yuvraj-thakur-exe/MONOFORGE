## 📖 About The Project

MonoForge elevates developer profiles from boring markdown lists into high-impact, visual software portfolios. It integrates 100% Camo-safe 60fps vector SVGs, 3D isometric contribution skylines, live streak telemetry, and customizable bento grids.

### ⚡ Built With
- [Next.js 16](https://nextjs.org/)
- [React 19](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Zustand](https://zustand.docs.pmnd.rs/)
- [Vitest](https://vitest.dev/)

## 🚀 Getting Started

### Prerequisites
- Node.js 20+
- pnpm or npm

### Installation
```bash
git clone https://github.com/yuvraj-thakur-exe/MONOFORGE.git
cd MONOFORGE
npm install
npm run dev
```

Visit `http://localhost:3000` to launch the Studio.
